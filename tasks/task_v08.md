## 1. Кейс

Одна система обслуговує два корпуси. Частина користувачів має бачити лише свій корпус, а адміністратор — обидва. Треба реалізувати обмеження видимості об'єктів.

## 2. Дані варіанта

- Корпус A — ліміт 10000 Вт, пристрої a-01, a-02
- Корпус B — ліміт 8000 Вт, пристрій b-01
- користувач A бачить лише Корпус A
- адміністратор бачить обидва корпуси

## 3. Завдання

1. створити два корпуси з різними лімітами та пристроями;
2. реалізувати список видимих об'єктів для користувача (visible_location_ids);
3. користувач повинен бачити лише дозволені об'єкти;
4. приховати чужі об'єкти у переліках пристроїв і приладів;
5. повертати 404 (а не 403) при доступі до чужого об'єкта;
6. покрити обмеження доступу тестами.

## 4. Що здати

- код у теці `students/<прізвище>/variant-08/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: права доступу, фільтрація вибірок, безпечна поведінка ендпоїнтів.
