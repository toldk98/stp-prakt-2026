# Варіант 03 — Один лічильник: добові показники

|                  |                                                        |
| ---------------- | ------------------------------------------------------ |
| **Слайс**        | B — Лічильники та показання                        |
| **Домен**        | один об'єкт, один пристрій PZEM                                          |
| **Складність**   | базова                                       |
| **Блоки курсу**  | ЛР3–ЛР5, ПР2–ПР4                                          |
| **Куди здавати** | `students/<прізвище>/variant-03/`             |

## 1. Кейс

Один лічильник pzem-001 щопівгодини фіксує напругу, струм, потужність, енергію, частоту та коефіцієнт потужності. Треба зберегти добові показники та обчислити зведену статистику.

## 2. Дані варіанта

- пристрій pzem-001, uart_mode=pzem, фаза L1
- 24 записи з інтервалом 30 хв
- напруга ≈ 230 В (±1), частота 50 Гц, power_factor 0.95
- потужність зростає від 460 Вт до 966 Вт
- енергія зростає від 12.5 до 21.3 кВт·год

## 3. Завдання

1. згенерувати й зберегти 24 показники pzem-001 за добу;
2. для кожного показника зберігати voltage, current, power, energy, frequency, power_factor, recorded_at;
3. обчислити середню, мінімальну та максимальну потужність за добу;
4. обчислити спожиту енергію як різницю першого й останнього показника;
5. знайти запис із максимальним струмом;
6. відсортувати показники за часом і вивести історію.

## 4. Що здати

- код у теці `students/<прізвище>/variant-03/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: робота з часовими рядами, агрегація показників, обчислення енергії.
