|                  |                                                        |
| ---------------- | ------------------------------------------------------ |
| **Слайс**        | B — Лічильники та показання                        |

| **Складність**   | підвищена                                       |
| **Блоки курсу**  | ЛР3–ЛР7, ПР4–ПР6                                          |
| **Куди здавати** | `students/<прізвище>/variant-04/`             |

## 1. Кейс

На вводі об'єкта стоять три лічильники — по одному на фазу. Треба зібрати показники, порахувати виміряне навантаження кожної фази та виявити дисбаланс між фазами.

## 2. Дані варіанта

- pzem-L1 — фаза L1, ліміт фази 5000 Вт
- pzem-L2 — фаза L2, ліміт фази 5000 Вт
- pzem-L3 — фаза L3, ліміт фази 5000 Вт
- щогодинні показники за 12 годин
- навантаження фаз: L1 ≈ 3000 Вт, L2 ≈ 1500 Вт, L3 ≈ 500 Вт

## 3. Завдання

1. створити три пристрої та прив'язати їх до фаз;
2. згенерувати й зберегти показники для кожного пристрою;
3. зібрати для кожної фази «виміряне навантаження» (measured_load);
4. порахувати залишок для кожної фази відносно її ліміту;
5. обчислити коефіцієнт дисбалансу (max−min)/середнє для фаз;
6. визначити найзавантаженішу фазу та її стан.

## 4. Що здати

- код у теці `students/<прізвище>/variant-04/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: групування за фазою, агрегація з кількох пристроїв, аналіз дисбалансу.
