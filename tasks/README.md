# Завдання (варіанти)

Наскрізний кейс курсу — навчальне ядро **`power_calc_edu`**
(сервер розрахунку електроспоживання).

Варіант визначає доменний слайс і набір даних, з якими студент працює протягом
семестру. Технічний кістяк (шари `routes → services → storage → models`)
однаковий для всіх — роботи зіставляні.

Схема: **5 слайсів × 2 набори параметрів = 10 варіантів.**

| № | Слайс | Назва | Складність |
| - | ----- | ----- | ---------- |
| [01](task_v01.md) | A | Квартира: прилади та профілі споживання | базова |
| [02](task_v02.md) | A | Офіс: прилади та робочий профіль | базова |
| [03](task_v03.md) | B | Один лічильник: добові показники | базова |
| [04](task_v04.md) | B | Три лічильники: баланс фаз | підвищена |
| [05](task_v05.md) | C | Добові профілі та історія розрахунків | підвищена |
| [06](task_v06.md) | C | Розрахунок за струмом і напругою | базова |

## Правила роботи з репозиторієм

1. Працюєте **лише у своїй теці** `students/<прізвище>/`.
2. Не змінюйте чужі теки та теку `tasks/`.
3. Конфлікти злиття відпрацьовуються у `playground/` (див. ПР6).
4. Кожне завдання — окремий коміт з осмисленим повідомленням.
