# Варіант 10 — XLSX-звіт по об'єктах

|                  |                                                        |
| ---------------- | ------------------------------------------------------ |
| **Слайс**        | E — Збереження та звіти                        |
| **Домен**        | формування звіту для керівництва                                          |
| **Складність**   | підвищена                                       |
| **Блоки курсу**  | ЛР7–ЛР8, ПР6–ПР8                                          |
| **Куди здавати** | `students/<прізвище>/variant-10/`             |

## 1. Кейс

Наприкінці місяця потрібен звіт у форматі Excel: об'єкти, прилади та показники лічильників на окремих аркушах. Треба зібрати дані, відсортувати й вивантажити у файл.

## 2. Дані варіанта

- аркуш «Об'єкти»: назва, тип, ліміт, навантаження
- аркуш «Прилади»: назва, потужність, фаза, об'єкт
- аркуш «Показники»: час, напруга, струм, потужність, енергія

## 3. Завдання

1. зібрати дані з усіх трьох сутностей;
2. сформувати XLSX-файл із трьома аркушами;
3. додати заголовки колонок і відсортувати рядки;
4. підсумувати навантаження за об'єктами;
5. повернути файл клієнту через HTTP-відповідь;
6. обробити випадок порожніх даних (файл усе одно формується).

## 4. Що здати

- код у теці `students/<прізвище>/variant-10/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: робота з бібліотекою openpyxl, формування файлу, HTTP-відповідь.
