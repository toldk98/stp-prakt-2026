## 1. Кейс

Офіс має техніку, частина якої представлена багатьма однаковими одиницями (лампи, монітори). Треба врахувати кратність приладів і порахувати навантаження робочого профілю.

## 2. Дані варіанта

- ПК — 400 Вт, фаза L1
- монітор — 60 Вт, фаза L1, кратний (6 шт.)
- принтер — 900 Вт, фаза L2
- кулер — 100 Вт, фаза L2
- освітлення — 40 Вт, фаза L3, кратне (10 шт.)
- кондиціонер — 2500 Вт, фаза L3
- профіль «Робочий день», ліміт 4000 Вт

## 3. Завдання

1. реалізувати CRUD приладів із підтримкою кратності (qty);
2. позначити прилади, які можуть мати кілька екземплярів (allow_multi);
3. створити профіль «Робочий день» з лімітом 4000 Вт;
4. додати до профілю прилади з урахуванням кількості;
5. порахувати сумарну потужність та залишок;
6. визначити, за якої кількості ламп офіс виходить на стан critical.

## 4. Що здати

- код у теці `students/<прізвище>/variant-02/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: кратність приладів, множення потужності на кількість, аналіз порогів.
