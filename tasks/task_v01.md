# Варіант 01 — Квартира: прилади та профілі споживання

|                  |                                                        |
| ---------------- | ------------------------------------------------------ |
| **Слайс**        | A — Прилади та профілі                        |
| **Домен**        | побутова квартира, три фази                                          |
| **Складність**   | базова                                       |
| **Блоки курсу**  | ЛР2–ЛР5, ПР1–ПР4                                          |
| **Куди здавати** | `students/<прізвище>/variant-01/`             |

## 1. Кейс

Ви проєктуєте облік електроспоживання квартири. Треба вести список побутових приладів із потужностями та фазами, об'єднувати їх у профілі споживання та рахувати сумарне навантаження відносно ліміту профілю.

## 2. Дані варіанта

- холодильник — 300 Вт, фаза L1
- пральна машина — 2200 Вт, фаза L2
- чайник — 1800 Вт, фаза L1
- телевізор — 150 Вт, фаза L3
- кондиціонер — 1500 Вт, фаза L2
- профіль «Вечір», ліміт 5000 Вт

## 3. Завдання

1. реалізувати CRUD приладів (створити, перелік, редагувати, видалити);
2. для кожного приладу зберігати назву, базову потужність і фазу;
3. реалізувати створення профілю «Вечір» з лімітом 5000 Вт;
4. додати прилади до профілю та зберігати порядок (sort_order);
5. порахувати сумарну потужність профілю та класифікувати стан за шкалою normal / warning / critical / overload;
6. вивести залишок потужності (residual) для профілю.

## 4. Що здати

- код у теці `students/<прізвище>/variant-01/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: структура даних приладів, зв'язок «профіль ↔ прилади», логіка класифікації.
