## 1. Кейс

Електрооблік ведеться не по квартирі загалом, а по дереву об'єктів: будинок → поверх → кімната → розетка. Кожен вузол має свій ліміт.

## 2. Дані варіанта

- Будинок — ліміт 15000 Вт
- Поверх 1 → Кухня (5000 Вт), Вітальня (4000 Вт)
- Поверх 2 → Спальня (3000 Вт), Кабінет (3000 Вт)
- Розетки всередині кімнат

## 3. Завдання

1. створити дерево об'єктів щонайменше глибиною 3 рівні;
2. задати для вузлів ліміт max_power;
3. прив'язати прилади та пристрої до конкретних вузлів;
4. обчислити сумарний ліміт і сумарне навантаження вузла з дітьми;
5. перевірити, чи навантаження кімнат перевищує ліміт поверху;
6. показати вибране піддерево об'єктів.

## 4. Що здати

- код у теці `students/<прізвище>/variant-07/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: рекурсія/обхід дерева, агрегація по вузлах, зв'язки parent-child.
