# Варіант 05 — Добові профілі та історія розрахунків

|                  |                                                        |
| ---------------- | ------------------------------------------------------ |
| **Слайс**        | C — Розрахунок та історія                        |
| **Домен**        | квартира, три профілі за часом доби                                          |
| **Складність**   | підвищена                                       |
| **Блоки курсу**  | ЛР4–ЛР7, ПР3–ПР5                                          |
| **Куди здавати** | `students/<прізвище>/variant-05/`             |

## 1. Кейс

Протягом доби квартира споживає по-різному: вранці, вдень і ввечері задіяні різні прилади. Треба описати три профілі та вести історію кожного розрахунку.

## 2. Дані варіанта

- прилади: холодильник 300, плита 3000, чайник 1800, ТБ 150, лампи 100
- профіль «Ранок» — ліміт 3500 Вт
- профіль «День» — ліміт 2500 Вт
- профіль «Вечір» — ліміт 5000 Вт

## 3. Завдання

1. створити три профілі з різними лімітами;
2. для кожного профілю визначити власний набір приладів;
3. виконати розрахунок для кожного профілю;
4. зберігати кожен розрахунок в історії (дата, профіль, total, status);
5. вивести історію за весь час і окремо за вибраним профілем;
6. порахувати, скільки разів стан був overload або critical.

## 4. Що здати

- код у теці `students/<прізвище>/variant-05/`;
- `README.md` із коротким описом запуску та прийнятих рішень;
- тести на ключову логіку варіанта;
- приклад вхідних/вихідних даних.

## 5. Критерії

Оцінювання за загальною шкалою дисципліни («Критерії оцінювання СТП»).

| Результат | Бали |
|---|---|
| Завдання виконано повністю, код працює, рішення обґрунтоване | 90–100 % |
| Переважно правильно, незначні помилки/недоліки | 75–89 % |
| Основне виконано, але є суттєві недоліки | 60–74 % |
| Виконано окремі частини або код працює некоректно | 1–59 % |
| Не виконано / не відповідає завданню | 0 |

Додатково у цьому варіанті звертається увага на: зв'язок «профіль → розрахунок → історія», фільтрація історії, підсумки.
