## 1. Кейс

Потужність не завжди вимірюють напряму — іноді її рахують із напруги, струму та коефіцієнта потужності. Треба реалізувати розрахунок для однофазного та трифазного навантаження.

## 2. Дані варіанта

- однофазний: U=230 В, I=10 А, cosφ=1.0 → 2300 Вт
- однофазний: U=230 В, I=5 А, cosφ=0.5 → 575 Вт
- трифазний: U=400 В, I=10 А, cosφ=0.95 → 6581.9 Вт
- коефіцієнт трифазності √3 ≈ 1.7320508

## 3. Завдання

1. реалізувати функцію розрахунку потужності за струмом для 1 фази: P = U·I·cosφ;
2. реалізувати розрахунок для 3 фаз: P = √3·U·I·cosφ;
3. повертати результат у ватах і кіловатах, округлюючи до сотих;
4. обробити некоректні вхідні дані (від'ємні значення, cosφ > 1);
5. покрити розрахунок тестами на всі наведені приклади;
6. окремо перевірити граничні випадки (cosφ = 0; великий струм).
