# Git-шпаргалка для практичних робіт (СТП)

Мінімум команд, які реально знадобляться на занятті. Працюємо зі спільним
репозиторієм `stp-prakt-2026`: завдання читаємо з `tasks/`, свій артефакт
кладеш у `students/<прізвище>/variant-NN/pr1/design.md`.

Кутові дужки `<...>` — заміни своїми значеннями.

## 1. Перший запуск (один раз на комп'ютері)

```bash
git config --global user.name  "Прізвище Ім'я"
git config --global user.email "you@example.com"
```

Без цих двох рядків коміт не створиться.

## 2. Отримати копію репозиторію

```bash
git clone https://github.com/toldk98/stp-prakt-2026.git
cd stp-prakt-2026
```

## 3. Оновитися перед заняттям (головна команда — завжди)

```bash
git pull
```

Роби це на початку кожної пари, щоб бачити актуальні завдання.

## 4. Створити свою теку та файл артефакта

```bash
mkdir -p "students/Прізвище/variant-01/pr1"
touch "students/Прізвище/variant-01/pr1/design.md"
```

## 5. Зберегти результат (коміт)

```bash
git status                    # що змінилося
git add "students/Прізвище/variant-01/pr1/design.md"
git commit -m "ПР1: аналіз та декомпозиція задачі"
git push                      # відправити на сервер
```

Якщо `push` не вдався — спершу `git pull`, потім знову `git push`.

## 6. Скасувати помилку

```bash
git reset --hard              # повернути все, як в останньому коміті (обережно!)
```

На початку цього достатньо. Усе інше (`merge`, `rebase`, `stash`) — пізніше,
на ЛР.
