# stp-prakt-2026

Спільний репозиторій практичних занять з курсу
**ОК2.1 «Сучасні технології програмування»**.

Наскрізний кейс — навчальне ядро [`power_calc_edu`](../power_calc_edu)
(сервер розрахунку електроспоживання на FastAPI + SQLAlchemy).

## Структура

```
tasks/        завдання (варіанти v01…v10) — змінює лише викладач
students/     роботи студентів: students/<прізвище>/
playground/   майданчик для відпрацювання конфліктів Git (ПР6)
solutions/    еталонні розв'язки — змінює лише викладач
scripts/      службові скрипти (генератор завдань)
```

## Як працювати

1. Клонувати репозиторій і отримати свій варіант із `tasks/`.
2. Створити свою теку: `students/<прізвище>/` (перше заняття).
3. Працювати **лише у своїй теці**; не змінювати чужі теки, `tasks/`, `solutions/`.
4. Регулярно комітити з осмисленими повідомленнями.

## Варіанти

Схема: **5 доменних слайсів × 2 набори параметрів = 10 варіантів**.
Повний перелік — у [`tasks/README.md`](tasks/README.md).

| Слайс | Тема | Варіанти |
| ----- | ---- | -------- |
| A | Прилади та профілі | 01, 02 |
| B | Лічильники та показання | 03, 04 |
| C | Розрахунок та історія | 05, 06 |
| D | Об'єкти та доступ | 07, 08 |
| E | Збереження та звіти | 09, 10 |

## Генерація завдань

```bash
python scripts/generate_tasks.py
```

Перегенеровує `tasks/task_vXX.md` та `tasks/README.md` з визначень у скрипті.
