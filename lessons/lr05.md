|                  |                                                       |
| ---------------- | ----------------------------------------------------- |

| **Зв'язок**      | лекції 4, 7; реалізує план ПР5; продовжує ЛР4         |
| **Оцінювання**   | 5 балів                                               |

## Мета

Перетворити код варіанта на **структурований застосунок**: пакети, шари,
єдина точка входу. Реалізувати план рефакторингу з ПР5.

## Кроки

1. Перейти на пакетну структуру `src/<variant>/` з підпакетами
   `domain/`, `io/`, `analytics/`, `storage/`, `reporting/` та `__init__.py`.
2. Розділити шари за зразком ядра: логіка не знає про CLI; `storage`
   відокремлено від `domain`; залежності напрямлені **всередину**.
3. Усунути дублювання (правило «three strikes») і «запахи», знайдені в ПР5.
4. Єдина точка входу `main.py` з прапорцями:
   `--source mem|csv`, `--report json`, `--out report/`.
5. Описати публічні інтерфейси пакетів: що саме експортує кожен `__init__.py`.
6. Оновити тести під нову структуру; додати **інтеграційний тест**:
   `mem` і `csv` дають однаковий результат на одному наборі.
7. Оформити `README.md`: структура, запуск, приклади команд.

## Орієнтовне зіставлення шарів

| Шар у ядрі | Ваш підпакет | Відповідальність |
| ---------- | ------------ | ---------------- |
| `models/` | `domain/` | сутності та їхні правила |
| `services/` | `analytics/` | обчислення й сценарії |
| `storage/` | `storage/` | доступ до даних |
| `routes/` | `cli.py` / `main.py` | вхід і формування відповіді |
| — | `io/`, `reporting/` | читання даних, звіти |

## Артефакт

- пакетний застосунок `src/<variant>/`, що запускається;
- єдина точка входу з прапорцями;
- тести зелені, включно з інтеграційним;
- `README.md` зі структурою та прикладами запуску.

## Критерії (5 балів)

| Складова | Бал |

| Єдина точка входу з прапорцями | 0.5 |
| Тести, включно з інтеграційним | 0.5 |

## Типові помилки

- `import` із глибоких модулів замість публічного інтерфейсу пакета;
- циклічні залежності між підпакетами;
- логіка у `__init__.py`;
- CLI-логіка, що напряму читає файли замість шару `io`.
