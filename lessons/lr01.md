# ЛР1. Налаштування середовища. Запуск та аналіз ядра

|                  |                                                       |
| ---------------- | ----------------------------------------------------- |
| **Тривалість**   | 4 год                                                 |
| **Форма**        | індивідуально                                         |
| **Блок**         | 1 — середовище та скелет                              |
| **Зв'язок**      | лекція 1; спирається на ПР1; готує ЛР2               |
| **Оцінювання**   | 5 балів                                               |

## Мета

Підготувати робоче середовище, запустити **еталонне ядро** `power_calc_edu`,
зрозуміти його шарувату архітектуру та створити власний скелет проєкту
для свого варіанта.

## Кроки

1. Перевірити Python 3.11+ (`python --version`), налаштувати IDE і термінал.
2. Клонувати ядро `power_calc_edu`, створити venv та встановити залежності:
   `python -m venv .venv && . .venv/bin/activate && pip install -e ".[dev]"`.
3. Запустити ядро: `python -m seed`, `python main.py`; відкрити
   `http://127.0.0.1:8000/docs`, виконати `login` (`admin`) і `GET /api/appliances`.
4. Перевірити якість: `pytest -q` (42 тести) та `ruff check .`.
5. **Розібрати шари** і намалювати схему `routes → services → storage → models`;
   знайти в ядрі сутності, дотичні до свого варіанта.
6. Створити власний проєкт `students/<прізвище>/variant-NN/` зі структурою
   `src/`, `data/`, `tests/`, `README.md`.
7. Написати скелет `src/main.py`, який читає `data/config.json` і виводить
   статус застосунку свого варіанта; зробити перший коміт у свою теку.

## Артефакт

- працююче ядро (демонстрація `/docs`, логін, тести);
- схема шарів у `students/<прізвище>/variant-NN/README.md`;
- власний скелет проєкту, який запускається;
- перший коміт у спільному репозиторії практик.

## Критерії (5 балів)

| Складова | Бал |
| -------- | --- |
| Середовище налаштовано, ядро запускається | 1.0 |
| `pytest` і `ruff` проходять | 1.0 |
| Схема шарів коректна й усвідомлена | 1.5 |
| Скелет власного проєкту працює | 1.0 |
| Чистий перший коміт | 0.5 |

## Підказки

- не комітити `.venv/` і `data/*.db` — перевірте `.gitignore`;
- `seed` створює локальну БД у `data/` — шлях видно в логах;
- якщо порт зайнятий, змініть його прапорцем запуску, а не редагуванням коду.
