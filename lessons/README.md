# Заняття

Карточки занять курсу. Практичні (ПР) — проєктують, лабораторні (ЛР) — будують.
Кожна лаба спирається на рішення відповідної практики; дублювання немає.

## Назва теки варіанта

У карточках плейхолдер `variant-NN` означає **двозначний номер** варіанта
`01…10` (збігається з нумерацією `tasks/task_v01.md … task_v10.md`).
Приклад для варіанта 1: `students/<прізвище>/variant-01/` (не `variant-1`).

Разом: 8 ПР × 2 год (20 балів) + 8 ЛР × 4 год (40 балів).

## Принцип зв'язку ПР → ЛР

- **ПР** дає рішення/дизайн: декомпозицію, вибір структур, план класів,
  план рефакторингу, схему API.
- **ЛР** реалізує це рішення кодом і доводить до запуску.
- Практика блоку передує лабораторній того ж блоку.
