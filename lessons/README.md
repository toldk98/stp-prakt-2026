## Принцип зв'язку ПР → ЛР

- **ПР** дає рішення/дизайн: декомпозицію, вибір структур, план класів,
  план рефакторингу, схему API.
- **ЛР** реалізує це рішення кодом і доводить до запуску.
- Практика блоку передує лабораторній того ж блоку.
